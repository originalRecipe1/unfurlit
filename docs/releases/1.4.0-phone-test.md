## Findings and follow-up

### Phone results reported on 2026-10-10

The owner reports that all links they tested work on the phone. Android Settings
shows **46.69 MB user data** and **48 MB app size**. These observations are also
recorded in [issue #54](https://github.com/originalRecipe1/unfurlit/issues/54) as
the starting point for the storage work in #54 and #55.

The exact tested APK, actual test date, Android version and device class have
not yet been confirmed. The last APK supplied for testing was the separate,
debug-based **Unfurlit Link Check** app with 64 links seeded in History:
`Unfurlit-1.4.0-LINK-CHECK.apk`, SHA-256
`de7432dfa367eb2d4b1136beca260e864072ad22ba39d624030ba93d49edae37`.
It is 34,778,928 bytes. The signed, optimized release APK from `666816e` is
19,960,325 bytes, SHA-256
`08ab55543ed235bc67d464fab9a472c72157c03241b23c12656ac39100cb4064`.
The previously quoted `bf842e06...` hash identifies the earlier unsigned release
APK, not either of these installable APKs.

Link Check and release are different build variants, so the app-size readings
need a matching variant before comparison. No compilation-reset result or
breakdown of the user-data increase has been reported; ART compilation and
History/cache growth remain unverified explanations. No phone was connected
over ADB when checked on 2026-10-10, so no reset was performed.

The link report does not separately confirm the release-upgrade, retained
History, GIF gestures, background audio/headset controls, app-sharing,
mobile-data or picture-in-picture checks. Those outcomes remain unfilled until
confirmed by the tester.
