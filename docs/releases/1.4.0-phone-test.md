## Storage baseline and build attribution

Use **45.29 MB user data / 37.94 MB app size** as the release starting point for
[issue #54](https://github.com/originalRecipe1/unfurlit/issues/54) and
[issue #55](https://github.com/originalRecipe1/unfurlit/issues/55).

The 48 MB app-size reading belongs to Link Check: its 34,778,928-byte APK plus
13,408,686 bytes of extracted native-library payload is approximately 48.19 MB.
This accounts for the reading by build variant. The supplied signed, optimized
release candidate is 19,960,325 bytes; it is a different package/build from
Link Check. Neither the 46.69 MB debug user-data reading nor its 48 MB app size
is the release baseline. The exact installed release APK hash, test date,
Android version and device class remain **not reported**.
