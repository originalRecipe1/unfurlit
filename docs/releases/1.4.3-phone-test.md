## Installation

The update check below needs the previous release installed with the same
signing key. The [1.4.2 phone APK](1.4.2-phone-test.md) was signed with the
standard debug key, so a phone that still has it can take the 1.4.3 debug-signed
CI APK with `adb install -r`, keeping History. If the installed app uses the
release signing key instead, uninstall it first. This clears History, and the
update check then stays NOT VERIFIED on the phone; the
[API 30/36 emulator record](1.4.3-emulator-test.md) covers retention across a
release update. Record which procedure was used. Do not substitute the debug or
Link Check variant for the CI release APK.
