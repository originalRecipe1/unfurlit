# 1.4.2 release upgrade — 2026-10-16

**VERIFIED on API 30 and API 36 x86_64 emulators.** These checks cover the
1.4.1 → 1.4.2 release update; the physical-phone record is still untested.

- Baseline: published 1.4.1 / 14 source at
  `c2ebe5e09f91a12457f1e73a42a3ed2a812a8fd2`.
- Candidate: 1.4.2 / 15 at `f9d66ab5ea0e24016891acdac1abe5396c86ff05`.
- Both APKs are actual release variants with R8 and resource shrinking enabled,
  source-built engines and no debug flag or diagnostic hooks. An external Gradle
  init script selects x86_64 only; shipping release ABI selection remains ARM64.
- Both are zipaligned and signed with the same temporary test key. No private
  key is committed. APK hashes and certificate digest are in the linked records.
- Both emulators use `swangle_indirect`. Open `youtube-video` and `x-photo-post`
  in 1.4.1 through the normal share intent, wait for real thumbnails, then use
  `adb install -r` without clearing data. Compare rows and thumbnail hashes,
  inspect History, extract `tumblr-photo-post`, then force-stop/restart.
