# 1.4.1 release upgrade — 2026-10-10

**VERIFIED on API 30 and API 36 x86_64 emulators.** This replaces the phone
upgrade check for 1.4.1. The phone will use a fresh debug-key-signed copy of the
merge-commit CI release APK; its results remain
[blank and not verified](1.4.1-phone-test.md).

## Builds and method

- Baseline: release variant at `v1.4.0`, full revision
  `c2a1b5cacf4cf4e58e7eee3b14147d910d142b52`, version code 13.
- Candidate: 1.4.1 / 14 on main `d0ad73b` plus this release PR. The PR records
  the final tested head and APK hashes alongside its CI/F-Droid results.
- Both are actual **release** variants with R8 and resource shrinking enabled,
  using source-built yt-dlp. The baseline retains its original wheel-based
  gallery-dl build; 1.4.1 uses the pinned sources. No diagnostic observer or test
  hooks are added to either app. The APK manifests are not debuggable.
- An external Gradle init script changes **only release ABI selection** to
  x86_64 for these emulators. The committed shipping ABI stays ARM64:

  ```groovy
  gradle.beforeProject { project ->
      project.pluginManager.withPlugin('com.android.application') {
          project.extensions.getByName('androidComponents').finalizeDsl { android ->
              def release = android.buildTypes.getByName('release')
              release.ndk.abiFilters.clear()
              release.ndk.abiFilters.add('x86_64')
          }
      }
  }
  ```

- Both aligned APKs are signed with **one temporary emulator-only key**.
  Certificate SHA-256:
  `7e4e44ccdf95009292982707074210806cd175cc03a02cc722c72e1b4dee21e8`.
  The private key is never committed or used for publication or the phone APK.
- On each clean emulator install, open `reddit-gallery` (three photos) and
  `x-photo-post` (four photos) through the normal exported share intent. Wait
  for real extraction results and nonempty JPEG thumbnails in History. These
  are live visits, not seeded database rows.
- Capture History rows and thumbnail SHA-256 values with read-only SQLite
  queries, and inspect the installed runtime. Use `adb install -r` for 1.4.1,
  with no uninstall or data clearing between versions.
- Confirm the old rows and thumbnail bytes immediately after installation,
  open History, then extract the new `reddit-gallery-share` fixture (four
  photos). Force-stop/restart and inspect History again.
- Compare every regular file in the new bundled Python archive with the
  installed copy by SHA-256. Verify the archive-size installation marker and
  all 49 additional removal targets from #58. Thumbnail comparisons use the
  stored bytes, not network refetches; the History screens are also inspected.
