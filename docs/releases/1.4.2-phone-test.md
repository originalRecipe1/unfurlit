## Installation

If the installed app uses the release signing key, uninstall it before installing
the supplied debug-key-signed CI APK. This clears History; the emulator upgrade
check covers retention across a release update (verified on [API 30 and API 36](1.4.2-emulator-test.md), not on the phone). A debug-signed previous test APK
can instead be updated with the same debug key, but record which procedure was
used. Do not substitute the debug or Link Check variant for the CI release APK.

## Release gate

After this PR merges, wait for Android CI on that exact merge SHA to pass,
download its unsigned release artifact, record its SHA-256, zipalign and
sign a copy with the standard debug key, and verify signature and alignment.
Hand the owner that APK and an `adb install` command. Enter the full tested
40-character merge SHA in `release-tag.yml` only after the phone checks pass.
No tag or release is created by this PR.
