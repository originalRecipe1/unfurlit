Unfurlit 1.4.1 (version code 14) builds gallery-dl and its five Python dependencies from pinned source submodules instead of PyPI wheels. The preparation script copies the sources and licenses, generates urllib3's version file from a checked-in template, and Gradle assembles the executable archive without pip or wheel installation. yt-dlp and EJS keep their existing source build.

The proposed metadata enables submodules and includes the preparation steps. AutoUpdateMode remains None; Binaries and AllowedAPKSigningKeys are retained. The 1.4.1 commit is still a placeholder until the release PR is merged and tested. The PR records local F-Droid build, source/APK scan and exact-head unsigned CI comparison results; comparison against a published signed 1.4.1 APK remains pending.
