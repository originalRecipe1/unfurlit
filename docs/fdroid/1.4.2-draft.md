# 1.4.2 F-Droid recipe draft

The [draft recipe](1.4.2-draft.yml) targets 1.4.2 / 15. Its commit is a placeholder
until the release merge commit exists. The canonical recipe remains the merged
1.4.1 metadata. A new fdroiddata MR is needed because AutoUpdateMode is None.

The build still uses pinned source submodules for yt-dlp, EJS, gallery-dl and
its dependencies, with no gallery-dl wheels. Gradle stages gallery-dl itself.
For prerelease validation only, substitute the PR commit in a temporary copy
and omit Binaries/AllowedAPKSigningKeys because no published 1.4.2 APK exists.
Compare its unsigned output with CI from that exact source revision. After
publication, retain those fields and verify the full signature-copy comparison.

Validation results will be recorded after the local build and scanners finish.
No fdroiddata submission is made by this release PR.
