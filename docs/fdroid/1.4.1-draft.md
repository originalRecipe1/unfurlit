## Build steps

- `submodules: true` checks out yt-dlp, EJS, gallery-dl and its five request
  dependencies at the repository's pinned gitlinks.
- Debian supplies `git make nodejs npm python3 tar zip`.
- `prebuild` stages gallery-dl, requests, urllib3, idna, certifi and
  charset-normalizer from those sources. The script generates urllib3's version
  file from the checked-in template and includes source licenses. It makes no
  downloads and runs no pip, wheel installer or Python build backend.
- `build` constructs yt-dlp and EJS from their pinned sources and sets the
  checksum-checked Gradle override. Gradle independently stages and assembles the
  same gallery-dl sources as a deterministic executable archive.
- The 1.4.1 build does not use gallery-dl or dependency wheels. The historical
  1.3.1/1.4.0 blocks retain their original behavior. CI's separate source-to-wheel
  audit is a comparison, not an input to the release or F-Droid build.
- Python's stdlib remains unpacked. Only the audited runtime removals from #58
  reduce storage; there is no stdlib ZIP or build-time bytecode compilation.
